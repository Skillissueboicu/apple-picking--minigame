# Farmer-Quest
Prototypen er et 3D casual game til tablet, mobil og web, udviklet i Unity til både single- og multiplayer. Spillet kombinerer 3D-gameplay og 2D-minigames for at vække nysgerrighed hos elever i 5.-6. klasse om klimasmart landbrug og landbrugsuddannelsen gennem naturfaglige udfordringer.
